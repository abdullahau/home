# CLAUDE.md

Personal site for Abdullah Mahmood. Started as a clone of the Zola template
behind [ellie.wtf](https://ellie.wtf), rebuilt with Abdullah's own identity,
content sections, and a manual light/dark theme toggle.

## Tooling

The site is built with [Zola](https://www.getzola.org/), a static site
generator written in Rust. There is no npm/node toolchain here.

Install Zola with Homebrew, not apt:

```
brew install zola
```

Common commands (via `justfile`):

- `just build` — runs `./build.sh`, which regenerates
  `content/_git-dates.json` (last-git-commit dates for `work`/`projects`
  pages, read by `templates/wiki-page.html`) and then runs `zola build`.
- `just serve` — build, then `zola serve` for local live-reload preview.
- `just clean` — removes `public/` and the generated git-dates file.

Never edit `content/_git-dates.json` by hand — it's a build artifact
(gitignored) regenerated by `build.sh` on every build.

## Content structure

- `content/work/` — case studies / professional work highlights. Wiki-style
  section (`templates/wiki-section.html` / `wiki-page.html`): title +
  `description` + tags, no post date shown on the list.
- `content/notes/` — short technical notes. Date-ordered
  (`templates/section.html` / `page.html`).
- `content/projects/` — personal projects. Same wiki-style template as
  `work`.
- `content/blog/` — longer-form writing. Same date-ordered template as
  `notes`.
- `content/about.md` — top-level page (About + CV: bio, experience,
  education, skills, contact). Currently scaffolded with `<!-- TODO -->`
  placeholders — fill in real content before publishing.

Each of `notes` and `projects` has one `example-*.md` page showing the
expected front matter for that template style — delete those once real
content exists.

## Style

Terminal-styled theme (`sass/style.scss`, compiled by Zola itself via
`compile_sass = true` — no separate Sass toolchain needed). Dark mode:

- By default follows the OS/browser `prefers-color-scheme`.
- A toggle button in the header (top right, `#theme-toggle` in
  `templates/base.html`) lets the visitor force light or dark, stored in
  `localStorage["theme"]` and applied via `data-theme="light"|"dark"` on
  `<html>`.
- The dark color rules live once, in the `dark-theme` Sass mixin near the
  bottom of `style.scss`, and are `@include`d both inside the
  `prefers-color-scheme: dark` media query (guarded by
  `:not([data-theme="light"])`) and unconditionally under
  `html[data-theme="dark"]`. When adding new dark-mode styles, add them to
  the mixin, not to either call site directly.
